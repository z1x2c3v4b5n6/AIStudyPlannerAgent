## C-4 残留问题

- **完全漏召回五条。** java-007、ai-010、ai-011、ai-012、ai-015 的自然语言描述与字段术语仍缺少足够的直接证据。完全漏召回指 Top-8 没有任何预期结果。
- **宽泛查询仍缺多样性。** java-012 在 Top-8 漏掉集合概览和线程池，Spring 相关项占据多个位置，GC 也从第 2 降至第 7。独立逐条评分没有按子主题重新分配名额。
- **部分词面命中会挤压相关条目。** ai-005 中「稳定性」和「输入输出」让采样、Token 条目领先于 Few-shot。ai-014 中「召回率」让向量检索排名高于 RAG Evaluation。ai-016 的 Agent Planning 在第 5，ai-017 的 Agent Workflow 在第 5。
- 同义词和权重是在这 30 条固定案例上调试的。分领域增长证明这些案例上的改善，无法估计新查询的真实效果。边界回归独立覆盖混合语言、词边界、重复同义词和无结果行为。

值得对 Embedding 做离线对照实验。五条完全漏召回中，多条是可通过语义相似度验证的改写，适合对比 C-4、向量检索和混合检索。先准备独立的口语改写、跨领域和多意图案例，比较 Top-3/Top-8 指标、延迟及错误归因。java-012 的主题覆盖需要单独衡量，语义相似度本身无法保证多个子主题都有结果。
