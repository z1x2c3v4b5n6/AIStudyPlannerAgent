# C-5 实验协议

在最终集首次运行前固定本协议、cases.json、config.json 和模型文件 SHA-256。

- 原 30 条用于复现和诊断，8 条新增 dev 用于检查配置，20 条新增 final 用于一次最终比较。三者分别计分。未对最终集搜索参数。
- 初始参数固定为等权 RRF、k=60、候选池20、余弦阈值0.30。dev 若无明显改善，也允许保留失败配置并报告。此次不进行参数搜索。
- 采用门槛为 final 的 Hit@3、Recall@3、MRR@3 均提升，legacy Hit@3 不下降，final 负例返回率不增加，CPU查询估算P95低于100ms。任何一项未达标均维持 C-4 默认实现。
- 正例沿用 C-3 的宏平均指标与实际返回数作为 Precision 分母。负例不计入正例平均，独立计量返回任意结果的比例。相关列表是评估目标，未列出的条目不保证全部无关。
- 多主题覆盖定义为多个相关 ID 的案例中，Top-K 覆盖相关 ID 的比例，再对这些案例平均。
- Semantic 对全部字段拼接文本做 mask mean pooling、L2归一化和余弦检索。单领域过滤在排名前完成，空领域检索全部55条。缓存只保存知识向量，查询每次重新编码。
- 语义查询计时覆盖 tokenization、ONNX推理与余弦排名，每条预热一次后采样5次。关键词由真实Java检索器预热5次后采样20次。Hybrid延迟为两者加融合实测耗时的串行估算，Python/Java之间没有常驻RPC。
- CPU单线程，量化ONNX。实验不覆盖并发负载、模型训练、在线服务、GPU和用户满意度。报告记录模型初始化、冷索引、热缓存及文件大小。
- 知识文本最长128 tokens，超过时截断。词表、模型权重固定到同一个提交并校验哈希。变更字段、模型、文本格式或长度会使缓存失效。损坏缓存重新计算，推理异常显式失败，禁止静默伪造指标。
